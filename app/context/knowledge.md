## Exercise Reference — Muscle → Best Exercises

| Muscle | Sub-region | Top exercises |
|---|---|---|
| Chest | Upper (clavicular) | Incline barbell/DB press, incline cable fly |
| Chest | Mid/lower (sternocostal) | Flat barbell bench press, flat DB press, weighted dips |
| Back | Width (lats) | Pull-ups, lat pulldown, straight-arm pulldown |
| Back | Thickness (mid-back) | Barbell rows, seated cable rows, chest-supported rows |
| Back | Lower back (erectors) | Deadlifts, Romanian deadlift, back extensions |
| Shoulders | Lateral delt | Dumbbell lateral raise, cable lateral raise |
| Shoulders | Rear delt | Face pulls, reverse pec-deck fly |
| Shoulders | Anterior delt | Overhead press (usually sufficient from pressing) |
| Biceps | Overall | Barbell curl, incline DB curl, hammer curl |
| Triceps | Overall | Overhead triceps extension, pushdowns, close-grip bench |
| Quads | Overall | Back squat, front squat, leg press, hack squat |
| Hamstrings | Hip-hinge | Romanian deadlift, stiff-leg deadlift |
| Hamstrings | Knee-flexion | Leg curl, Nordic curl |
| Glutes | Extension | Hip thrust, glute bridge, RDL |
| Glutes | Abduction | Cable hip abduction, banded lateral walk |
| Calves | Gastrocnemius | Standing calf raise |
| Calves | Soleus | Seated calf raise |
| Core | Flexion | Cable crunch, hanging leg raise |
| Core | Rotation | Cable woodchopper, Russian twist |
| Core | Stability | Plank, Pallof press, dead bug |

## Programming Quick Reference

| Goal | Reps | Sets/muscle/week | Rest |
|---|---|---|---|
| Strength | 1–6 | 6–15 | 3–5 min |
| Hypertrophy | 6–20 | 10–20 | 1–3 min |
| Endurance | 15–25+ | 6–12 | 30–90 sec |

- Train each muscle 2–3x/week for best results
- Add weight/reps over time (progressive overload) — the single most important variable
- Sets taken within 0–3 reps of failure drive hypertrophy; you don't need to train to absolute failure every set
